# 나만의 주식펫을 키움 (모의 서비스)

매주 소수점 주식을 조금씩 모으면, 펫이 **모은 조각만큼 아래에서부터 색이 차오르고** 1주를 채우면 도감에 오르는 키움증권 MTS 기획 프로토타입.
KDA 1기 2차 프로젝트(포디움/큐밍)를 재설계한 버전입니다.

## 실행 (로컬)

필요: **Node.js 22.5 이상** (`node -v`로 확인, 낮으면 `brew upgrade node`)

```bash
cd 2차프로젝트/podwoom
npm install
npm run dev
```

- 화면: http://localhost:5173 (첫 화면 터치 → 홈)
- API: http://localhost:3001 (화면이 /api 로 자동 연결)
- 첫 실행 시 데모 데이터(33주 동안 모아 온 상태: 도감 3마리 + 키우는 중 3마리)가 자동 생성됩니다.
- 예전 버전의 `data/pet.db`가 있으면 자동으로 지우고 새로 만듭니다.

## 캐릭터 테마

| 업종 | 우리 캐릭터 (기본) | 큐밍 (시안 · 메뉴에서 선택) |
| --- | --- | --- |
| 반도체·IT하드웨어 | 룡룡이 | 칩밍 (칩 배지) |
| 자동차 | 토깽이 | 부릉밍 (레이싱 헬멧) |
| 인터넷·소프트웨어 | 삐약이 | 초록밍 (헤드셋) |
| ETF | 도룡이 | 모아밍 (3마리 무리) |
| 바이오 | 삐약이 | 새싹밍 (새싹) |
| 금융 | 토깽이 | 동전밍 (동전 목걸이) |

실서비스에서는 종목명·기업개요·업종으로 캐릭터를 자동 생성하는 것을 가정합니다.

## 폴더 구조

```
podwoom/
├── server/              Express API (포트 3001)
│   ├── index.js         라우트 · 호출 제한 · dist 서빙
│   ├── game.js          모의 시간 · 정기매수 · 색 차오름 · 1주 완성 · 도감 · 적립 관리(줄이기/쉬기/멈춤/해지)
│   ├── agent.js         펫 대화: 새 펫 데려오기 · 그만두고 싶을 때 대안 · 현황 · 용어 · 회사 소개 · 가드레일
│   ├── broker.js        주문 어댑터 (sim / 키움 MCP 연결 지점)
│   ├── market.js        주간 시세 (네이버·Yahoo, 실패 시 모의 시세)
│   ├── universe.js      종목 14개 + 업종별 캐릭터 · 펫 이름
│   ├── terms.js         용어사전
│   └── db.js            SQLite (data/pet.db)
├── src/
│   ├── App.jsx          화면 전환 · 메뉴
│   ├── chars.js         캐릭터 테마 A/B (그림 · 색 · 소품)
│   ├── components/      Splash · PetReveal(색 차오르는 펫) · Icon
│   └── screens/         Home · ChatSheet · Graduate · Town(마을/도감) · DexDetail · QrFlow · PushPreview
├── public/pets/         a/ 큐밍 SVG 6종 · b/ 기존 캐릭터 PNG 4종
└── DEPLOY.md            디지털오션 배포 계획
```

## 환경 변수 (.env, 선택)

| 변수 | 용도 |
| --- | --- |
| OPENAI_API_KEY | 규칙에 없는 자유 대화 답변 (없으면 안내 문구) |
| naver_Client_ID / Client_Secret | 회사 소개 때 최근 소식 한 줄 |
| BROKER_MODE | `sim`(기본) · `kiwoom`(배포 단계 연동 예정) |
| HOST / PORT / DATA_DIR | 배포용 (기본 127.0.0.1 / 3001 / ./data) |

## 설계 원칙

- 종목 추천·매매 권유 없음 (가드레일), 예상 수익 미표시, 홈·알림에 수익률 없음
- 보상은 꾸준함에만 (금요일 칸 · 연속 기록 · 1주 완성) — 매매 빈도와 무관
- 해지는 막지 않음: 이유를 묻고 대안을 보여 준 뒤 최대 3번 눌러 해지, 모은 조각은 계좌에 그대로
- 알림은 금요일 한 통 + 일이 있을 때만 (규칙은 앱의 ⋯ → 알림 미리보기)
